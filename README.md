Fetch & Async/Await Practice

A small JavaScript practice project focused on working with external APIs and handling asynchronous operations.

About

The project loads users from an external API and renders them in a table.

The main focus is practicing:

fetch()
async/await
JSON parsing
HTTP response handling
response.ok
try/catch
throw new Error()
DOM manipulation
forEach()
API

The project uses JSONPlaceholder:
